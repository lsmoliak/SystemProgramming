How the math works

Each die is fair, so every combination of faces is equally likely. With 3 attacking dice and d defending dice there are 63+d combinations. Sort both hands high to low and compare the top pairs: highest vs highest, then second vs second. The higher die wins; the defender wins ties.

3 vs 1. The attacker wins if their highest die beats the defender's die. For a defender roll of k, the attacker loses only if all three dice are ≤ k, which happens k³ ways. Summed over k = 1…6: 1+8+27+64+125+216 = 441 losing combos out of 6×216 = 1296. So the attacker wins 855/1296 ≈ 65.97%.

3 vs 2. The two comparisons depend on each other, so there is no tidy closed form. The page counts all 7776 combinations directly. That gives 2890 where the defender loses 2, 2611 where each side loses 1, and 2275 where the attacker loses 2.
